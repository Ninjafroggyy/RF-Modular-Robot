# datalayer/ — Future Data Handling Module (Not Implemented)

This folder is reserved for potential future features related to **data capture, storage, and retrieval** from the robot system. 
While not currently in use, it serves as a placeholder for organising future enhancements involving:

---

## Possible Features (Not Implemented)

If expanded, this module might include support for:

- **Recording camera video streams**  
  Capturing and saving live video frames from the robot’s camera to local storage, possibly in compressed formats like MP4 or WebM.

- **Recording microphone audio streams**  
  Streaming and saving raw or encoded audio data (e.g. WAV, AAC) received from the robot’s microphone.

- **Data timestamping and synchronisation**  
  Applying timestamps to audio and video for playback accuracy or future data analysis.

- **Playback/replay systems**  
  Enabling review or debugging of previous robot sessions by playing recorded streams through the UI.

- **Storage management and configuration**  
  Handling file size limits, storage location, retention policies, and user toggles for enabling/disabling recordings.

---

## Current Status

> **Recording functionality is *not* implemented, and there are *no current plans* to add it.**  
> This module exists purely as a structural placeholder to guide future development if data persistence becomes a requirement.
